Fan-made Game

Prisoner of Love

A personal H5 project inspired by a favorite character and built as a playful, self-expressive tower defense experiment.

Overview

This project uses a lightweight HTML5 canvas workflow to deliver a compact strategy game with a strong visual identity. It blends fan-made energy, playful UI design, and a build-your-own defense loop that emphasizes iteration and experimentation.

Highlights

  • Rapid prototyping with browser-first tooling and a compact gameplay loop.
  • Aesthetic direction shaped by custom art references and creative iteration.
  • A personal project that explores expression beyond traditional commercial production.
